# Swmarly Valheim Seed Totem

This is an unofficial Valheim 1.0 port of the original SeedTotem mod.

The Seed Totem disperses stored seeds in an area around it.

Place the normal totem using the Hammer by default. The build menu can be changed in the configuration. It costs:

    5 Fine Wood
    5 Greydwarf Eyes
    1 Surtling Core
    1 Ancient Seed

Use a seed with the item hotkeys to restrict the totem to a single type of seed. Hold Use
to add all permitted seeds in your inventory. The green glow fades when the totem runs out
of seeds. It also works with trees.

Give the totem a whack to harvest all ready plants in the area. (Trees are not harvested.)

## Advanced seed totem

Select the Hammer while near an Artisan Table to place the Advanced Seed Totem. It plants in a
rectangular area and costs 10 Fine Wood, 10 Greydwarf Eyes, 2 Surtling Cores, and 1 Ancient Seed.

Its model is assembled from the current Valheim 1.0 vanilla prefabs so the port remains visible
and placeable in-game.

## Configuration

Server settings control dispersion radius, timing, planting limits, harvest-on-hit, cultivated
ground and biome checks, and build costs. Client settings control the build menu, queue display,
colors, and keyboard shortcuts. Existing configurations are retained.
